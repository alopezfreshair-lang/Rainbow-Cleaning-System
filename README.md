# Rainbow Home Demonstrations – Angel Lopez

Independent demonstration site operated by Angel Lopez. Not operated by Rexair or the Rainbow manufacturer.

Single-page site: `index.html` is fully self-contained (images, CSS and JavaScript are built in).

## Publish on GitHub Pages
1. Create a new repository on GitHub and upload everything in this folder (keep `index.html` in the root).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
